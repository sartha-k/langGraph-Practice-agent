LangGraph Practice Playground 🤖

A beginner-friendly project for learning and experimenting with LangGraph workflows, state management, and AI agent orchestration.

This repository contains small hands-on examples demonstrating how to build stateful AI pipelines using nodes, edges, and shared state.

🚀 Features
Stateful workflow management using StateGraph
Multi-node execution pipelines
Shared state using TypedDict
Conditional routing logic
Dynamic state updates
Basic agent workflow experimentation
🛠️ Tech Stack
Python 3
LangGraph
LangChain
